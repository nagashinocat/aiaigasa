# 絶対に相合傘をやめさせないゲーム 設計書

2026-11-18

## ねらい

相合傘で歩く男女2人を、プレイヤーが「空」として見守るゲーム。天気はだんだん晴れていくので、プレイヤーは雨を降らせ続けて二人の相合傘を守る。二人は相合傘の間だけ話せて、会話が進むほどドキドキが高まり、最後にデートの約束をする。口出しできない空の立場から、雨だけで二人を後押しする「もどかしさ」と「見守る楽しさ」が芯。

## ゴール

- スマホのブラウザで、説明なしにすぐ遊べる
- 1回のプレイは1〜2分(帰り道ひとつ分)
- 雨の表現だけは綺麗に見せる(このゲームの見どころ)
- クリアすると、少し晴れた夕方の空に虹がかかって終わる

## やらないこと

- 凝ったキャラクター絵、歩きアニメーション(絵は背景と傘のシルエット程度)
- プレイヤーが会話の選択肢を選ぶ仕組み(空は口を出せない)
- ステージ選択、セーブ、ランキング

## 失敗とみなすもの(アンチゴール)

- 雨がただの飾りに見えて、「空として降らせている」実感がないこと
- メーターを見るだけの作業になり、二人の会話が目に入らないこと

## 遊びのルール

- 画面を押している間、雨が強まる。指を離すと弱まる
- 何もしなくても天気は少しずつ晴れに傾く(雨が自然に弱まる)
- 雨の強さには「ちょうどいい帯」がある。メーターで常に見える
  - 弱すぎる状態が続く → 二人が「止んだね」と傘を閉じる
  - 強すぎる状態が続く → 二人が軒下に駆け込む
  - どちらも、二人が「また明日」と言って別れ、ゲームオーバー
  - 一瞬はみ出しただけでは終わらない。はみ出している間、猶予ゲージが減り、尽きたら終わり(私の判断:厳しすぎると会話を読む余裕がなくなるため)
- ちょうどいい帯にいる間だけ、会話が進み、ドキドキゲージが上がる
- 会話の山場(「あのさ…」など)では晴れに傾く力が強くなり、帯も狭くなる
- ドキドキゲージ満タンで、デートの約束の会話 → 雨が上がり、夕方の空に虹 → クリア

## 画面

```
┌───────────────────┐
│ ドキドキ ■■■■□□□□  │
│                   │
│  ╲ ╲ 雨 ╲ ╲ ╲     │
│     「あのさ…」     │  ← ふきだし
│      ▲傘▲         │  ← 二人と傘のシルエット
│ ▁▁▁▁街並み▁▁▁▁▁   │
│ 雨の強さ [弱|ちょうどいい|強] │
└───────────────────┘
```

- 主役は会話のふきだしと雨。キャラクターはシルエット
- 雨:雨粒の数・速さ・角度、地面の波紋、空の色(灰色→明るい灰→夕焼け)が雨の強さと天気に合わせてなめらかに変わる
- クリア演出:雨粒がまばらになって止み、空が夕焼け色に、虹がゆっくりかかる

## オープニング(本人の追加)

- 水滴のついたガラス。ガラスの手前で葉っぱに雨が当たって揺れ、しずくが落ちる(葉はくっきり)
- その奥に、傘を差した男女がぼやけて見える
- ガラスに「while it's raining」と描かれていく
- 私の判断:ガラスは少し曇っていて、文字は指でなぞったように一筆ずつ現れる。なぞった線のところだけ曇りが取れて奥がくっきり透ける。文字が書き終わったら「押して雨を降らせよう」を出し、タップでゲーム開始(この場面がタイトル画面を兼ねる)。WebGLが使えない端末では、ぼかした2Dの絵と文字で同じ構図を出す

## 作り方(Approaches)

- A. 絵もすべてコードで描く1ファイル版:手ざわり重視、絵はシンプル
- B. ドット絵スプライト版:見た目は一番かわいいが、絵の準備が重い
- **C. 文字とふきだし中心版(採用)**:いちばん早く作れる。弱点の「雨を降らせている気持ちよさ」は、雨の表現だけ手をかけて補う、という方針で本人が選択

## 本人が決めたこと

- プレイヤーは空。雨を降らせ続けて相合傘を守る
- ドキドキゲージが上がり、満タンでデートの約束
- 押すと雨が強まり、離すと弱まる
- 弱すぎても強すぎても相合傘は終わる
- 二人は相合傘の間だけ話せる
- 失敗したら「また明日」で別れてゲームオーバー
- 作り方は C、雨だけは綺麗に
- 最後は少し晴れた夕方の空に虹

## 作る人に任せること(私の判断を含む)

- 技術:HTML1ファイル。雨はWebGL(本人が選択):手前・奥で大きさとぼけを変えた雨粒、画面を流れて背景をゆがませる水滴、街灯のにじみ。WebGLが使えない・重い端末では2D Canvasの雨に自動で切り替え。空・街並みは背景描画、ふきだし・メーターはHTML/CSS。外部ライブラリなし
- 会話の中身:10〜15行ほどの1本のストーリーを私が書く。あとで差し替えやすいよう、会話はファイル冒頭の一覧にまとめる
- 数値(晴れに傾く速さ、帯の幅、猶予の長さ)は遊びながら調整
- 音は最初は入れない(あとで雨音を足す余地は残す)
- スタート画面はタイトルと「押して雨を降らせよう」の一言だけ。ゲームオーバー後はワンタップでやり直し

## 追加:複数の物語(2026-11-19)

- オープニングのあと物語を選ぶ画面。5本:はじめての相合傘 / 転勤(ついてきてほしいが切り出せない男) / 留学(切り出せない女) / 無口な男と構ってほしい女 / 転校する小学生の女の子(友だち同士の別れ、恋愛にはしない)
- 本人の決定:返事は「雨が上がる少し前に聞き、虹が出て答える」。全物語共通
- 本人の決定:憧れの先生の物語は入れない
- 私の判断:物語ごとに会話・問いかけ・答え・失敗時のせりふ(最後に心の声)・終了画面の見出しを持つ。雨が止む速さ/山場の厳しさを物語ごとに少し変える。小学生の物語は二人のシルエットを小さく描く。終了画面に「もう一度」と「物語をえらぶ」
- クリア演出:問いかけ → 雨が止む(0-3秒) → 夕焼け(3-6秒) → 虹(6-9秒)、虹の途中(7秒)で答え → 終了画面(11秒)
